# Critical E2E
1. Admin theme draft → preview → publish → guest sees theme.
2. Guest QR → voice → knowledge answer.
3. Guest request towels → confirmation → ticket.
4. Staff accept → update → complete.
5. Guest says unresolved → reopen.
6. Tenant A cannot access tenant B.
7. Voice disconnect → reconnect/fallback text.
