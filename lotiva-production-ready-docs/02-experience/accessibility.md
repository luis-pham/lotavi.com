# Accessibility

Mục tiêu WCAG 2.2 AA.

Bắt buộc:
- keyboard navigation;
- visible focus;
- contrast tự động kiểm tra;
- screen-reader labels;
- không dùng màu là tín hiệu duy nhất;
- touch target tối thiểu 44x44;
- reduced motion;
- transcript thay thế audio;
- hỗ trợ zoom 200%;
- semantic heading;
- form error gắn đúng field;
- live region cho ticket/reconnect nhưng không spam.
