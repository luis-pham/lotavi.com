# Screen: Guest Home
## Goal
Khách thấy ngay nơi lưu trú, hoạt động tiếp theo, thông báo và hành động chính.
## Layout
Cover → logo/tên → room/cabin → next activity → assistant CTA → quick actions → open requests → announcements → popular information.
## Primary action
“Nói chuyện với trợ lý”.
## States
Loading theme/context; expired QR; no schedule; no announcement; open ticket; weak network.
## Acceptance
Tải mobile nhanh, theme đúng tenant, không lộ ID nội bộ, CTA hoạt động bằng touch và keyboard.
