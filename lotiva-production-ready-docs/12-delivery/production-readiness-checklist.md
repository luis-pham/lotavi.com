# Checklist

- Product acceptance complete.
- UX all states.
- Accessibility AA.
- Localization.
- Tenant isolation.
- Security review.
- Migration tested.
- Rollback tested.
- Backup and restore tested.
- Monitoring and alerts.
- Rate limits.
- Load test.
- E2E critical paths.
- Audit logs.
- Privacy/retention.
- Incident and deployment runbooks.
- No critical/high blocker.
