# Governance

Platform locked:
safety, privacy, no hallucination, no compensation promises, tool authorization, confirmation, prompt injection defense.

Tenant editable:
assistant name, greeting, tone, brevity, vocabulary, brand pronunciation, handoff phrasing.

Admin workflow:
draft → validate → preview → test → publish → rollback.

Session đang chạy không đổi prompt giữa chừng.
